# SF SOLUTIONS Website

Single-page business website for SF SOLUTIONS, including computer sales, IT support, CCTV, networking, server support, customer promise, and contact details.

## Files

- `index.html` - Main website page
- `assets/logo.jpeg` - Website logo
- `assets/professional-support.jpeg` - About section image

## GitHub Pages

1. Upload all files to a GitHub repository.
2. Go to repository `Settings`.
3. Open `Pages`.
4. Choose the `main` branch and `/root` folder.
5. Save and wait for GitHub Pages to publish the site.

The site uses Tailwind CSS and Lucide icons from CDN links, so an internet connection is required for full styling and icons.
